# Source Register

Private working files are not copied into this repository. This register names
the source collections used to prepare version 0.1.0 so claims can be reviewed
without turning the repository into an archive.

| Source | Date/status | Use in v0.1.0 |
|---|---|---|
| [ImmDS + HALO FHIR IG working draft](https://github.com/immregistries/immds-halo-fhir-ig-working-draft) | Initial commit September 3, 2026; working draft | Primary source for the technical subject areas, current FHIR exploration, and open issues |
| *IG Narrative — First Pass Draft* | February 12, 2026; private working document | Background for Knowledge Base and guidance-provenance distinction |
| ImmDS + HALO progress presentations | January–June 2026; meeting/review inputs | History of terminology, examples, and unresolved questions |
| *ImmDS + HALO IG content plan* | September 3, 2026; working plan | Gap checklist and proposed guide coverage |
| Contextual Conditions repository | October 29, 2026; public working proposal | Current definition and boundaries of the related concept |
| InteropHub topic 1 and meeting records | Current community record | Topic identity, relationship, stage, and discussion context |
| Original ImmDS guide and difference summary | Earlier baseline; publication status to confirm | Compatibility and history for later review |

Before adding a source, confirm that the citation or description is public-safe.
Do not add recordings, partner proposals, private URLs, or source copies merely
because they informed drafting.
